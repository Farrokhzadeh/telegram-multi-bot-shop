## Shared-core brand writer primitive — 2026-11-13
`BrandWriterStore` adds revision-bound admission and authenticated, audited pause/resume using the existing`brands.active` and`policy_version` fields. Admission checks the trusted brand/bot identity and exact policy revision, then holds the brand row through the caller's business transaction. Missing, paused, foreign-bot or stale admission aborts that transaction. Pause waits for participating admitted transactions; resume advances the policy revision so old admissions remain invalid. Existing administrator authentication and immutable enable/disable audit commands protect control changes. A replay returns the original command result without reversing a later state; current state is read separately. The deployment/configuration revision remains a separate identity.
`OutboxStore.ClaimForBrandAsync` reuses the existing lease/deduplication implementation with admission and a brand predicate. It cannot claim another brand's or a global job. Existing global`ClaimAsync` behavior is retained and is **not** a per-brand fence. Admission must share the mutation transaction and follow the reviewed path's lock order; privileged writers retain the existing authenticate/audit-first order. The synthetic checkout wrapper below takes admission first, which does not qualify that ordering for other writer paths. Qualification calls`AcceptLocalAsync` within that admitted transaction. Wrapping an operation that opens another transaction is not qualified.
