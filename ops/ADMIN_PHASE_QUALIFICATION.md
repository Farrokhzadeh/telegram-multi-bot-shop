## Administration

AdminCatalogStore and the opt-in CatalogEndpoints implement shared master edits, per-brand inherit/override/clear listing fields, exact USD/manual-toman prices, quantity/publication policy, current FX metadata and brand policy/required-channel reads. Independent active administrator authentication, original brand scope, typed audit commitments and expected revisions govern mutations. Earlier order quotes, payment destinations, source bindings and manual retail prices are not reconstructed from later edits. Required-channel enforcement reuses its canonical before/after audited policy writer.

Inventory import accepts bounded write-only synthetic credentials, encrypts them with the restricted inventory keyring and serializes deduplication across imports, including retained key versions. Metadata reads expose no ciphertext, credentials or fingerprints. Duplicate/conflicting imports roll back; replay returns the original command result. Stock changes queue canonical FIFO/restock work without performing a delivery or supplier purchase.

OrderAdministrationStore supplies scoped/global stable order pagination, exactly-once explicit USD wallet corrections, and audited blocking hold/resume/local-preorder cancellation. Cancellation preserves original accepted money, frozen terms and FIFO timestamp, returns the entire still-held claim once, and records no repayment, payout, wallet reversal or fabricated refund. An acquired/released/resolved obligation rejects stale cancellation. Actual FIFO draining/allocation workers remain their later tasks.

Supplier retry/credit requires the original request/revision, a terminal failed request, no active leased procurement or acquired remote units, and absence of unresolved original submits. Unknown/timed-out submits require later original-attempt lookup evidence explicitly marked confirmed_no_effect before safe retry. Retry preserves immutable source/account/cost/quantity and queues work with the exact authorization audit/revision. A request with a separately approved cost override remains in its later cost-review workflow. Credit retains internally acquired local units for administrators, preserves original paid history and releases the whole held claim atomically; wallet/crypto uses the frozen net USD total, while bank requires an explicit positive confirmed USD amount. A zero-money obligation cannot mint a fictitious credit and remains protected for its separately authorized resolution workflow. No provider was called or externally reconciled.

Receipt decisions and receiving destinations reuse the qualified T040 services. The coupon endpoint reuses the T043 unrestricted owner-edit service, including paid-entitlement edits without a cap floor. Typed revision history and audit reads exclude recoverable code values. ## API contract

OpenApiContract derives an OpenAPI document from registered routes and source-generated JSON metadata, refuses unprotected/unregistered admin routes and freezes the implemented request/response shapes and pagination. Write-only token/card/credential inputs are marked; ordinary response schemas exclude protected values. Strict JSON rejects unknown/duplicate properties, missing required constructor inputs and invalid nulls. Common admin HTTP errors use redacted code/server request-ID envelopes; current independent bearer sessions govern every route. Native smoke exports the generated contract for artifact inspection. These are opt-in routes, not normal host activation or a claim that every future endpoint is implemented.
