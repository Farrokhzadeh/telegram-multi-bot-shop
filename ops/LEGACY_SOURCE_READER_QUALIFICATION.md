LegacySourceReader reads the public.users and public.transactions projections declared by AccAbad-Shop at 66371a23a1c8149dc5bdf89a0355aa689d454dba. It requires an explicitly approved host, port, database and username. Every operation uses a read-only repeatable-read transaction with UTC timestamps and bounded queries.
InspectSchemaAsync produces a versioned SHA-256 commitment over public column names, types, nullability, precision, defaults and the sorted Django migration set. This is a new reader-specific fingerprint format: review it against the approved copy before placing it in an import manifest. It is not interchangeable with an earlier arbitrary schema digest and does not fingerprint constraints, indexes or migration file contents. Source-revision and full deployed-schema qualification remain required.
ReadWalletAsync verifies that commitment within the same snapshot used to read a user and all bounded ledger rows. It uses numeric::text and ExactDecimal, preserves the authoritative USD balance, rejects nonzero balance_irr, unsupported language and inactive/banned accounts, and requires exact manifest proofs before returning data. Missing or extra history targets reject the import. History has no invented balance_after.
ImportWorkflow composes this reader with the existing atomic mapping/opening/history writer and redacted reconciliation report. Only the authoritative opening posts; history stays non-posting. A replay preserves the same mappings and opening. No source writer, normal-host activation or new schema is added.
